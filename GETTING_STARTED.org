* 🎯 Your First Steps

** 1. Start with Module 1 (30-45 minutes)

Module 1 covers *ownership* - Rust's most important and unique feature.

#+begin_src bash
cd modules/01_basics_ownership

# Read the README first
cat README.org

# Run the interactive exercises
cargo run

# Run the examples
cargo run --example ownership_basics
cargo run --example move_semantics

# Run the tests
cargo test
#+end_src

** 2. Experiment and Break Things!

The best way to learn Rust is to *make mistakes* and read compiler errors:

1. Open =src/main.rs= in your editor
2. Uncomment the lines that say "This will cause a compilation error"
3. Try to compile: =cargo run=
4. Read the compiler error message carefully
5. Understand WHY it doesn't compile
6. Fix it and try again

** 3. Take Notes

Use [[file:PROGRESS.org][PROGRESS.org]] to document your learning:
- What concepts clicked for you?
- What's confusing compared to C++?
- Questions to revisit later

Example entry:
#+begin_example
** Session 1 - [2024-01-15]

*** Topics Covered:
- Ownership basics, move semantics

*** Key Insights:
- Move is the default for heap types (unlike C++)
- The compiler prevents use-after-move at compile time!
- No need for std::move() - moves are automatic

*** Comparison with C++:
- Rust's ownership is more strict than C++ move semantics
- No "valid but unspecified state" - moved values are INVALID
- Similar to unique_ptr but enforced for ALL types

*** Questions/Challenges:
- When should I use clone() vs references?
- How do I share data between multiple functions? (Module 2!)

*** Next Steps:
- Module 2: Borrowing and Lifetimes
#+end_example

* 💡 Tips for Success

** 1. Embrace the Borrow Checker
Don't fight it - learn from it! The compiler is teaching you to write safer code.

** 2. Compare with C++
You have a huge advantage! Use your C++ knowledge:
- Ownership ≈ unique_ptr (but for everything)
- References ≈ C++ references (but stricter)
- Arc/Rc ≈ shared_ptr
- RAII works the same way (Drop trait)

** 3. Read Compiler Errors
Rust has the BEST compiler errors. They:
- Explain what went wrong
- Show you where the problem is
- Suggest how to fix it
- Include helpful links

** 4. Use the Playground
Try quick experiments at https://play.rust-lang.org/

** 5. Join the Community
- r/rust on Reddit
- Rust Users Forum
- Rust Discord
- Ask questions - the community is friendly!

* 🐛 When You Get Stuck

1. *Read the error message* - 80% of the time it tells you exactly what to do
2. *Check the Quick Reference* - [[file:QUICK_REFERENCE.org][QUICK_REFERENCE.org]]
3. *Review the module README* - Concepts explained there
4. *Run the examples* - See working code
5. *Search the error* - Google the error code (e.g., "E0382")
6. *Ask for help* - Community is friendly!
